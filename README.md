# 🔐 DRF Authentication & Authorization System

Система аутентификации и авторизации на базе **Django REST Framework** с использованием JWT и кастомной ролевой модели доступа.

Проект реализует:

* ✅ Регистрацию и логин
* 🔑 JWT-аутентификацию (через `JWTManager`)
* 🔒 Хеширование паролей (`PasswordHasher`)
* 👤 Профиль пользователя
* 🗑 Soft delete аккаунта
* 🛡 Ролевую модель (user / admin)
* ⚙ Управление бизнес-сущностями и правилами доступа
* 🌱 Автозаполнение базы через `seed_data`

---

## 🛠 Технологии

* **Python 3**
* **Django**
* **Django REST framework**
* JWT (кастомный `JWTManager`)
* PostgreSQL / SQLite
* Role-based access control (RBAC)

---

---

## 🚀 Основной функционал

### 🔐 Аутентификация

* `POST /register/` — регистрация
* `POST /login/` — вход
* `POST /logout/` — выход (удаление токена на клиенте)

После логина возвращается JWT-токен и роль пользователя.

---

### 👤 Профиль

* `GET /profile/` — получить профиль
* `PUT /profile/` — обновить профиль
* `POST /delete-account/` — мягкое удаление аккаунта

---

## 📌 Особенности

* Кастомная JWT-логика (без сторонних JWT-пакетов)
* Soft delete пользователя
* Ролевая модель через `UserProfile`
* Гибкая система правил доступа
* Разделение ответственности (serializers / utils / permissions)

---

## 📄 Назначение проекта

Подходит как:

* Базовая auth-система для SaaS
* Основа для микросервисной архитектуры
* Пример реализации RBAC + JWT на DRF
